# Predicción de Attrition / Rotación de Empleados

Proyecto de clasificación listo para Google Colab. Incluye EDA, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/attrition-empleados/blob/main/attrition_empleados_colab.ipynb)

- EDA (distribución, countplots, boxplot)

- Modelos: Logistic Regression, Random Forest, Gradient Boosting

- Feature importance
- **SHAP** (summary plot)
- Conclusiones

Dataset: IBM HR Attrition
